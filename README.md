# 🕹️ ARSCADE-ARDUINO — аркадный автомат BREAKOUT

Самодельный аркадный автомат на Arduino Uno: игра Breakout (Арканоид) на OLED-дисплее, управление джойстиком и **монетоприёмник на ультразвуковом датчике** — как в настоящих автоматах! 🪙

## 📦 Состав системы
- Arduino Uno
- OLED дисплей SSD1306 (128×64, I2C)
- Джойстик двухосевой (KY-023)
- Ультразвуковой датчик HC-SR04 (монетоприёмник)
- Мини-макетка для разводки питания

## 🔌 Схема подключения

| Модуль | Пин модуля | Пин Arduino |
|--------|-----------|-------------|
| OLED | SDA | A4 |
| OLED | SCL | A5 |
| Джойстик | VRx | A0 |
| HC-SR04 | TRIG | 9 |
| HC-SR04 | ECHO | 8 |

**Питание:** 5V и GND всех модулей — на общие рельсы макетки, от пинов 5V и GND Arduino.

## 🎮 Как это играет
1. Включение → заставка (Progress Bar → Hello World!)
2. Экран **BREAKOUT / INSERT COIN** (мигает)
3. Подносишь руку к датчику (5–15 см) → «монета принята» → игра!
4. Джойстик ← → двигает ракетку, разбивай кирпичи
5. 3 жизни ❤️, счёт, рекорд (HI)
6. Game Over → автомат снова просит монету

## 📚 Библиотеки (ставятся в Arduino IDE)
